# Jac reference routing

Primary online sources:

- https://docs.jaseci.org
- https://github.com/jaseci-labs/jac
- https://www.jac-lang.org

Local source-backed corpus:

Locate the repository root with `git rev-parse --show-toplevel`, then use its
`Jac docs/` directory.

Useful local paths:

- `official-docs/` — complete documentation source
- `core-examples/` — compiler-shipped examples
- `reference/jac-llmdocs.md` — condensed model context
- `upstream/jac/` — compiler, runtime, tests, and CLI implementation
- `upstream/jacpacks/` — official packaged application templates

Prefer current compiler diagnostics and tests over old examples when syntax
conflicts.
